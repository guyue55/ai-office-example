# 企业 AI 办公基座模板 v1.1.2

本版修复 v1.1.1 的 Agent 轮包依赖约束错误，并保留 v1.1.1 的迁移说明修正。产品运行代码、数据库迁移、权限与部署方式不变。

## 修复

- `clients/agent/pyproject.toml`：`office-client==1.1.0` 修正为 `==1.1.2`。
- `office-data-service/pyproject.toml`：`agent` 额外依赖 `office-agent==1.1.0` 修正为 `==1.1.2`。
- 因此 `office_agent-1.1.2` 轮包可与同版 `office-client`／`office-api-contracts` 正常解析安装；v1.1.1 的 Agent 轮包不可用，请使用本版。

## 继承自 v1.1.1 的修正

- 升级迁移 head 由 0015 修正为 0017（含 0016 临时模型探针、0017 进度快照）。
- README 更新为 v1.1 已发布状态；INSTALL 示例使用 `v$(cat VERSION)` 与时间戳候选目录。

## 升级与兼容

- Python 3.13／3.14；API 沿用 `/api/v2` 契约。
- 从 v1.0.0 升级须备份业务库、身份库和配置，执行全部 Alembic 迁移至 `0017`，包括 Agent 任务、会话、模型配置修订、连接测试记录与进度快照。不要只执行 0012 或通过全新安装重建现有实例。
- 迁移一次性把 `agent.run` 加入内置员工及既有 `access.manage` 权限集，并更新权限版本；管理员可调整或撤回。
- 当前内部执行器仅支持单进程；中断或在途写入结果未知时需人工核对，不自动重放。应用回滚不等于数据库可降级。
- 局域网 HTTP 仍仅限明确选择的演示模式；正式部署采用 HTTPS。

## 交付

完整源码、普通员工交付包、技能包、四个 Python 包（office-api-contracts、office-data-service、office-client、office-agent）的 wheel／sdist，共 17 份发布资产，含来源清单与校验文件。普通员工包不自动安装模型运行时；需要员工独立 Agent 时按 docs/AGENT_OPERATIONS.md 使用 `--with-agent` 单独打包。
