# 企业 AI 办公基座模板 v1.1.0

本版新增可选智能体能力：员工电脑独立 Agent、服务端内部助手与外部 AI 工具共用原有数据、实时权限及审计。普通服务端和客户端仍可独立运行，不要求配置模型。

## 新增与改进

- 独立 `office-agent` Python 包，支持 OpenAI Chat Completions、Responses 与 Anthropic 协议及获准的兼容端点；模型配置与企业登录分离。
- 服务端异步任务、持久会话、有界续问、停止与人工审批；HTTP、CLI、MCP 和控制台复用应用能力。模型不能自行批准写入，操作仍受原权限、版本、幂等与审计约束。
- 全局悬浮助手入口、桌面侧栏和完整工作区；历史搜索、改名、归档、受限 Markdown、实际工具回执及审批预览。
- 统一控制台导航、表单与弹窗、焦点、原生下拉增强和草稿保护；提交等待期间防止离页丢失回执，停用当前授权前确认草稿。
- 增加显式局域网 HTTP 演示实例迁址维护入口，原安装器仍拒绝静默换址或重建已有实例。

## 交付

完整源码、普通员工交付包、技能包、原三个 Python 包及新增 office-agent 的 wheel／sdist，共17份发布资产（包含来源清单和校验文件）。普通员工包不自动安装模型运行时；需要员工独立 Agent 时按 docs/AGENT_OPERATIONS.md 使用 `--with-agent` 单独打包。

普通服务镜像默认不包含 Agent 模型依赖。启用服务端助手需按运行指南显式构建 `OFFICE_AGENT=1` 镜像、配置获准模型及密钥引用，并核对就绪情况。Release 或镜像发布不自动升级服务器与员工电脑。

## 升级与兼容

- Python 3.13／3.14。API 新增能力沿用现有 `/api/v2` 契约；既有数据操作与统一响应保留。
- 从 v1.0.0 升级须备份业务库、身份库和配置，按部署流程执行全部 Alembic 迁移至 `0015`，包括 Agent 任务、会话、模型配置修订与连接测试记录。不要只执行0012或通过全新安装重建现有实例。
- 迁移一次性把 `agent.run` 加入内置员工及既有 `access.manage` 权限集，并更新权限版本；管理员可调整或撤回。模型仅在配置并明确批准数据处理后启用，不因迁移自动调用。
- 当前内部执行器仅支持单进程，不支持多worker抢占运行；中断或在途写入结果未知时需人工核对，不自动重放。应用回滚不等于数据库可降级。
- 局域网 HTTP 仍仅限明确选择的演示模式；正式部署采用 HTTPS。向量镜像不代表已实现通用 RAG 或自动脱敏。

### 管理员模型配置与双变体交付

- 控制台支持 OpenAI Chat、Responses 和 Anthropic 配置的保存、合成连接测试、显式应用与停用；权限、版本冲突和审计复用基座。保存不自动调用模型；测试需确认费用，启用需确认数据许可。
- 模型秘密使用独立根密钥加密，数据库备份必须配套保管该根密钥；错误／缺失密钥只使助手不可用，不阻断普通数据功能。出口与原始／解压响应预算独立限制。
- 安装配置增加 `OFFICE_AGENT=0/1`，镜像缺失时拉取，建库前校验镜像能力；环境变量与配置冲突则拒绝执行。
- 普通与 Agent 镜像使用同一 Dockerfile、独立 CI 矩阵；发布流程规划标签 `1.1.0` 与 `1.1.0-agent` 及各自 SHA 标签、摘要和 SBOM。工作流具备能力不代表远端镜像已经发布。
