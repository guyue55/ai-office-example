# 企业 AI 办公基座模板 v1.1.1

本版是 v1.1.0 的文档修正补丁：产品代码、API 契约（除版本号）、数据库迁移、权限与部署方式均不变，仅修正升级说明并重新构建发布资产，确保源码包、`RELEASE_NOTES.md` 与发布页一致。

## 修正

- `releases/v1.1.0.md`、`docs/AGENT_OPERATIONS.md`、`docs/RELEASE_READINESS_1.1.0.md`：升级迁移 head 由 0015 修正为 0017，覆盖 0016 临时模型探针与 0017 进度快照。
- `README.md`：更新为 v1.1 已发布状态，移除「分支正升级」等过期表述。
- `INSTALL.md`：发布示例改用 `v$(cat VERSION)` 与时间戳候选目录，`--artifact-dir` 同步使用变量。

## 与 v1.1.0 的关系

功能、接口、权限、迁移与部署方式与 v1.1.0 相同。已部署 v1.1.0 的实例无需因本补丁升级数据库或服务；新安装或从 v1.0.0 升级请按本文迁移至 0017。

## 升级与兼容

- Python 3.13／3.14；API 沿用 `/api/v2` 契约。
- 从 v1.0.0 升级须备份业务库、身份库和配置，执行全部 Alembic 迁移至 `0017`，包括 Agent 任务、会话、模型配置修订、连接测试记录与进度快照。不要只执行 0012 或通过全新安装重建现有实例。
- 迁移一次性把 `agent.run` 加入内置员工及既有 `access.manage` 权限集，并更新权限版本；管理员可调整或撤回。
- 当前内部执行器仅支持单进程；中断或在途写入结果未知时需人工核对，不自动重放。应用回滚不等于数据库可降级。
- 局域网 HTTP 仍仅限明确选择的演示模式；正式部署采用 HTTPS。

## 交付

完整源码、普通员工交付包、技能包、四个 Python 包（office-api-contracts、office-data-service、office-client、office-agent）的 wheel／sdist，共 17 份发布资产，含来源清单与校验文件。普通员工包不自动安装模型运行时；需要员工独立 Agent 时按 docs/AGENT_OPERATIONS.md 使用 `--with-agent` 单独打包。

普通服务镜像默认不包含 Agent 模型依赖。启用服务端助手需显式构建 `OFFICE_AGENT=1` 镜像并配置获准模型及密钥引用。
