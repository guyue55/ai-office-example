# 企业 AI 办公基座模板 v1.0.0

首个稳定版本的通用框架，供独立企业部署和二次开发。服务端与 Web 不调用模型、不运行 Agent；AI 交互位于员工客户端，客户端不直连数据库。

## 包含能力

- FastAPI 异步服务、PostgreSQL 18＋pgvector 镜像基线、Keycloak 身份及管理控制台。
- 浏览器 PKCE、系统安全凭证后端、续期协调与授权管理；用户、角色、权限集、实时权限与审计。
- 通用项目容器、动态字段修订、候选／确认／冻结／更正与历史；受控批量、查询、多维聚合及导出。
- 独立服务器与员工安装器，CLI／SDK、完整技能包及可配置产品品牌。
- 统一类型契约、错误码及 HTTP／MCP 适配；契约库 office-api-contracts／office_contracts。

## 交付与校验

- `enterprise-office-source-1.0.0.zip`：完整模板源码、安装入口、CI、测试和开发说明，不含 Git 历史。
- `enterprise-office-client-1.0.0.zip`：员工安装包；服务地址为公开占位值，安装时按管理员提供的地址配置。
- `office-skills.zip`：完整技能与规则，另需配套 CLI／SDK；不能只复制叶子 SKILL.md。
- 三个 Python 包的 wheel／sdist、依赖版本、来源清单及 SHA256SUMS。
- 服务镜像 `ghcr.io/guyue55/ai-office-example/data-service:1.0.0`：linux/amd64、linux/arm64；以发布说明列出的摘要固定部署，不跟随 latest。

下载后用 SHA256SUMS 校验；开发源码中的 `scripts/verify_release.py` 可进一步核验整套资产白名单、来源及归档边界。源码公开、Release、镜像与实际部署分别验收。

## 兼容与范围

Python 3.13／3.14；服务镜像使用 Python 3.13。仅预装向量扩展，不默认启用向量业务，不提供模型服务、任意 SQL 或行业指标成品。系统凭证后端、实际 AI 宿主发现、企业连接器、生产 HTTPS／容量及客户口径需在目标环境验收。局域网 HTTP 仅用于明确选择的 Demo 验收。

升级已有实例前按 INSTALL.md 与 docs/OPERATIONS.md 设计备份、迁移和恢复；安装脚本同配置续跑不等于无条件升级。
