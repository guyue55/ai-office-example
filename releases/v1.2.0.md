# 企业 AI 办公基座模板 v1.2.0

本版集中改进 Web 工作台的可读性与操作体验、智能助手配置页的信息层级，并补齐前端质量门禁与流动式模型响应的稳定性修复。数据模型、权限语义与部署方式与 v1.1.x 兼容；升级须执行新增迁移（见「升级与兼容」）。

## 主要变化

### 工作台界面

- 重建中性工作台与全页面语义结构；列表、详情与筛选按页面任务重新组织，说明和高级操作迁出分散展开区。
- 人员开通收敛入口并强制首次角色关联，支持默认角色选择与按需搜索刷新；修复动态开户角色初始化与关联失败恢复。
- 仪表盘角色权限改为卡片按需详情；管理表格改善长列表阅读、表头滚动与操作失败恢复。
- 桌面导航支持收缩与可访问提示；助手侧栏展开偏好不再影响列表摘要。
- 统一圆角刻度与动效令牌，补齐按压反馈与面板退出过渡；抽取页面标题宏，清理内联样式。
- 数据表格补自身可访问名称并与滚动区域区分；关闭面板与详情时同步撤出无障碍树，避免读屏器与自动化在同名元素间歧义。
- 修复候选框展开后仅剩已选项、展开按钮不能收起等问题。

### 智能助手

- 模型配置页简化为单卡片信息层级：连接、密钥、模型与高级设置，去掉步骤条与嵌套折叠。
- 保存语义明确为主操作「保存并启用」与次操作「仅保存草稿」；仅后者频繁使用时不再弹确认。
- 更改服务地址而沿用原密钥时，保存路径同样要求显式确认，避免提交后整页报错丢失已填内容。
- 会话标题去除控制符与方向符并按码点截断；模型用量按字段结构化展示。
- 补齐敏感信息清洗的键名变体与文本凭证识别。
- 修复流式响应被 SDK 收尾重放误判为截断（`invalid_response`）的问题。

### 质量与工具

- 新增样式规范门禁与前端规则门禁（内联样式、内联事件、`innerHTML`、原生弹窗、媒体查询格式与断点），基线双向锁定并接入 CI。
- 输出契约与输入契约交叉校验；修正两种业务码组合静默降级为 HTTP 500。
- 门禁脚本补齐自身回归，修正三处扫描误报。
- 开发栈补齐登录主题、模型密钥加密根密钥与身份校验配置。

## 升级与兼容

- Python 3.13／3.14；API 沿用 `/api/v2` 契约，业务码新增 `422001 invalid_input` 与 `422012 unsupported_operation` 用于原本误报 500 的路径。
- 从 v1.1.x 升级须备份业务库、身份库与配置，并执行全部 Alembic 迁移至最新 head。本版未新增迁移脚本，迁移链与 v1.1.2 相同；若实例仍停在旧 head，按 `docs/OPERATIONS.md` 补齐。
- 权限码与角色语义不变；本版未改动内置权限集。
- 当前内部执行器仍仅支持单进程；中断或在途写入结果未知时需人工核对，不自动重放。应用回滚不等于数据库可降级。
- 局域网 HTTP 仍仅限明确选择的演示模式；正式部署采用 HTTPS。

## 交付

完整源码、普通员工交付包、技能包、四个 Python 包（office-api-contracts、office-data-service、office-client、office-agent）的 wheel／sdist，含来源清单与校验文件。普通员工包不自动安装模型运行时；需要员工独立 Agent 时按 `docs/AGENT_OPERATIONS.md` 使用 `--with-agent` 单独打包。

## 验证边界

发布前检查与候选验收记录见 `docs/RELEASE_READINESS_1.2.0.md`。隔离测试不等于企业真实数据、所有模型供应商、目标容量或全部 AI 宿主验收。以下范围本版未验证：Safari／Firefox 的 `@view-transition` 与 `allow-discrete` 行为、真实读屏器、触屏按压反馈、深色模式（全仓尚无 `prefers-color-scheme` 规则）、真实供应商之外的模型连通性。
