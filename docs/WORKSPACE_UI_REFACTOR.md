可复用设计与复核经验已整理到[专题指南](UI_DESIGN_GUIDE.md)，长期协作入口见[AGENTS.md](../AGENTS.md)。本账本保留逐次事实，不替代长期规则。

## 调研与设计决策

| 对象 | 一手资料与开源实现 | 采用与取舍 |
|---|---|---|
| 基础与排版 | [Atlassian间距](https://atlassian.design/foundations/spacing)、[网格](https://atlassian.design/foundations/grid) | 使用有限间距尺度、页面与组件密度区分；中文系统字体 |
| 外壳与导航 | [Tabler源码](https://github.com/tabler/tabler)、[Fluent UI](https://github.com/microsoft/fluentui) | 稳定导航、页头、表面层级；不复制Bootstrap/React依赖或另造组件状态 |
| 列表与筛选 | [Carbon表格](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)、[Carbon源码](https://github.com/carbon-design-system/carbon)、[Shopify列表迁移](https://shopify.dev/docs/apps/build/app-home/migrate-from-polaris-react/resource-list) | 统一工具栏、可比较的列、行操作与局部滚动；不创造后端不支持的排序/导出 |
| 表单与恢复 | [GOV.UK校验](https://design-system.service.gov.uk/patterns/validation/) | 保留输入、摘要定位、就地错误；沿用现有增强校验及无JS原生回退 |
| 说明与浮层 | [WAI Tooltip](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)、[Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) | 可聚焦说明、Esc、焦点恢复；tooltip模式本身仍为WAI草案，不能据此宣称完整合规 |
| 助手 | [assistant-ui源码](https://github.com/assistant-ui/assistant-ui)、[GSAP响应动效](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/) | 阅读/输入/操作分区、宽窄视图共享会话；本轮无须新动画库 |

以上为适配本项目后的设计判断，不是实际用户研究。Polaris当前迁移资料优先于已归档React示例；开源项目作为设计和结构参照，不直接复制未经核验的代码。

## 实施顺序与完成门槛

1. 基线：提交列表摘要与侧栏状态修复，保留独立PG及浏览器证据。
2. 共享基础：独立设计变量文件；重构原样式引用，统一品牌、焦点、间距、圆角、表面；导航和位置栏可访问。
3. 页面与组件：统一页头和动作换行、筛选工具栏、表格密度与焦点、表单分组、面板/助手表面；逐组巡视，不增加业务字段。
4. 二次复核：全页面五宽度、无JS/减少动态、对比度/焦点、账号/表单/助手流程；检查失败及反例。
5. 分批提交实现与证据，检查当前本地服务；未验证的真人、模型和发布明确保留。

页面分组：概览；人员/角色/权限集/权限目录/审计/授权/操作记录；开户/关联/详情/安全/预览/回执；助手工作区/任务/详情；模型设置；登录恢复/错误/退出。共享组件优先于逐页补丁。

## 仪表盘按需详情复核

用户反馈指出完整角色和权限长表占据概览正文。此前把“呈现完整资料”放在“快速概览”之前，页面任务判断不足。本次参照[PatternFly可点击卡片](https://www.patternfly.org/components/card/)、[Dashboard设计](https://v4-archive.patternfly.org/v4/demos/dashboard/design-guidelines/)与[Carbon对话框边界](https://www.carbondesignsystem.com/building-blocks/core/patterns/dialogs)：概览卡提供摘要与详情入口；复杂操作不叠层。不是以“旧/流行”判断可用性。

- 账号、授权、角色卡整块可点击；数字属于同一原生链接，去掉额外“查看…↓”跳转。本人账号进入安全页，授权/角色复用共享详情弹窗。
- 角色及权限原节点按需移入共享record-dialog，关闭归还节点并回焦卡片；重复开合不复制状态或事件。无JS保留原生details和页内锚点阅读。
- 角色“查看配置”明确进入完整页，不再从弹窗上叠加抽屉；仍按原access.read显示入口。共用保留文字标记避免行操作图标增强在弹窗中被隐藏。
- 修改键/新标签行为保持原生链接；权限图形和长表仅在查看时出现，不占概览首屏。
- 初轮卡片开合、Esc、回焦、无叠层和全页巡视/共享提示3通过；加入实际角色页面跳转的助手组合回归3通过。最终补验无JS和完整离线结果另记。未用强制点击规避叠层问题。
- 最终证据：完整离线746通过、134 live排除；卡片专项（含无JS、实际角色完整页跳转）1通过；目录和对比度2通过；共享提示及助手组合回归均通过。首轮控制台74通过。重复检查不累加为独立场景。
- 二次视觉复核将卡片外跳箭头改为普通详情箭头，避免错误暗示外部页面。实现提交2d314d9；本地服务更新需重新登录；没有推送或发布。

## 第三轮：选择、检索与候选账号

研究参照：[Carbon表格行操作与工具栏](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)、[Carbon筛选](https://www.carbondesignsystem.com/building-blocks/core/patterns/filtering)、[PatternFly批量选择](https://www.patternfly.org/patterns/bulk-selection/)、[GOV.UK复选框](https://design-system.service.gov.uk/components/checkboxes/)。资料提供模式，不代表所有能力都适合直接启用；本轮只实现当前页选择，不提供未加载数据的全局全选。

- 授权关联：本页全选/部分选择、已选数量、其他页保留项数量、撤销本次修改及选中行反馈；保持原提交、版本与并发保护。全选只改变当前页可编辑项，不自动保存；reset默认完成后再同步摘要。
- 候选账号：先展示可比较的姓名/账号/状态，选定账号后展开关联表单，不同时铺开所有候选的输入区，不额外叠加弹窗。
- 审计、账号操作、客户端授权及助手任务列表：按各自允许的查询条件展示已应用筛选标签；逐项移除保留其他条件与范围，并清除页码。标签取已提交URL，不将未提交输入当作已筛选结果。简单搜索页不重复增加关键词标签。
- 新的筛选标签独立为共享组件，白名单与可读文案在一处维护；不引入前端查询状态副本。
- 初轮83通过、2失败：错误使用URL移除查询参数API导致筛选页500；已改为序列参数。回归86通过，单项移除测试验证保留范围/日期/页大小、重置页码与忽略不支持字段。

## 第四轮：重新建立页面结构与中性工作台视觉

本轮按用户明确要求重新审视旧布局，使用frontend-ui-engineering的组合/语义原则、UI UX Pro Max的Corporate Modern方向，以及GSAP Core的可中断与减少动态原则。旧阶段通过只作历史证据，不能阻止新设计。

### 分类型研究与实施
