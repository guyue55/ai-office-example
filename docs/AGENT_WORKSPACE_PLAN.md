## 目标、边界与方向

DIRECTION_APPROVED_FOR_IMPLEMENTATION：在既有模板／原生JS、共享Agent执行、当前员工权限与服务端任务审批上增加可复用助手交互。新增会话不改变权限模型，不运行独立模型循环。保留既有无会话任务，迁移仅新增表／可空字段。不开启在用实例、不升级全局工具、不推送／发布。源码、隔离数据库和浏览器验证由本轮授权覆盖。

主界面为固定入口、非模态右侧栏和独立工作区，共享一套消息／状态／审批展示。宽屏并排，小屏使用全页；关闭展示不取消任务，停止单独操作。所有批准仍使用任务版本＋服务端ticket，浏览器不能上传模型历史或替换工具参数。

## 数据与执行

1. 新增本人会话：标题、归属、版本、归档及时间。复用AgentRun作为每轮用户消息／执行／最终回复的唯一事实源，不再复制一份工具或消息日志。
2. AgentRun可关联会话，附受控页面标签与受理时本人权限指纹。会话内最多一个活动任务；归档要求无活动任务。跨会话仍受现有全局／本人限额约束。
3. 续问只读取服务端已有的有限历史，以有明确“不作为事实”的文本参考交给同一引擎。每页会话输出最多500000字节，单轮按契约库限制128000字节／4000节点／24层；超过则显式detail_truncated并指向原独立详情，不在侧栏批准未展示完整的预览。历史保留已结束轮次的失败／中断／结果未知标记，不把无回执当作未写入。历史轮数、字节、输入总预算均有上限；不回放旧工具调用／审批。不支持编辑旧消息、分支或自动摘要。
4. 当前员工有效权限／安全纪元指纹变化时旧轮次不送入模型；当前会话执行期间本人指纹变化则保守中止，避免旧数据继续外发。无关员工授权修改不影响此会话；指纹复用Access有效权限计算，不复制授权逻辑。无会话任务维持既有行为。历史界面对旧指纹隐藏正文与回执，仅显示权限变化提示。
5. 页面上下文只允许登记的页面枚举，是讨论位置提示，不是权限证明；不抓DOM／隐藏字段，不默认上传列表。未来选中业务对象须另走原读取权限，不在本轮凭空加入选中协议。
6. 原任务API／CLI／MCP兼容；新增会话操作复用应用注册、统一输出、原HTTP／SDK／CLI／MCP桥，不暴露为Agent递归工具。

## 交互与状态

- 一个面板组件用于侧栏和全页。用户正文用textContent渲染，结构化预览以可读字段卡片＋可展开原始详情显示；不允许模型HTML。
- 输入允许补充问题，按发送时的受控上下文快照。处理期间不接受同会话并发；切页保留会话ID和展开偏好，浏览器不持久化正文／回执／密钥。
- 请求全部同源，复用Web会话与CSRF；HTTP读取失败不重发写入；决定冲突刷新并重新核对，不自动批准新版本。
- 先采用自适应轮询：单个inflight、活动时更新、静止降频、隐藏停止、错误退避及明确上限，恢复时取快照；不做无限快速轮询。终态不重复查询；无逐字流式或WebSocket。
- 原生键盘和焦点：打开聚焦输入，关闭返回入口；业务区仍可操作；Esc不越过现有模态窗口；用户滚动查看历史时不强制拉到底部。尊重reduced-motion，不引入GSAP。
- 新任务／查询提示、未配置／无权限／会话归档／过期登录／请求冲突／预算耗尽／结果未知／停止均有明确状态。未知写入不重试。页面数据可能变化时提供刷新入口，不自动丢弃未保存表单。
