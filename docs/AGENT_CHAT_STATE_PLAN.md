# 当前任务通知与Tooltip归属：方案及验收

日期：2026-10-26；分支codex/agent；起点35d5403。范围仅共享前端交互，不改变服务端状态、执行、认证、审批或依赖。

## 问题与设计

1. 结果未知等终态的正文警告可见，但状态区仅“会话已同步”。以最新任务的服务端状态、停止请求和未知结果标记生成固定通知，覆盖排队、处理、待确认、写入在途、已完成、失败、中断、停止和结果未知。错误／权限／归档等现有优先级保留，不从LLM文字判定成功。
2. 相同任务相同阶段同步不重复更新通知；新任务相同终态仍产生通知更新。保留单一polite状态区，不将整个正文变成live region，不抢焦点、不播报记录内容或模型长文。
3. 提示分别跟踪焦点对象、悬停对象、提示本身悬停及主动关闭对象。以新输入意图切换提示，离开B时不能因A仍聚焦而保留B；可以回到A的有效提示。Esc关闭后滚动／resize不恢复，新的聚焦／悬停才解除相应关闭状态。

| C | 原场景回归及制品 | 真实同源BFF与隔离Chrome，保留审批／草稿／权限／断网回归；控制台模板检查、打包逐字节核对、源码扫描和本地提交 |

## 依据与边界

[WCAG状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)、[悬停／聚焦内容](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html)、[WAI Tooltip指导](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)支持非打断通知及触发对象生命周期管理。Tooltip指导仍在讨论中，不当作正式认证。

DOM语义及模拟测试不能证明所有读屏软件真实播报；VoiceOver／NVDA、Windows、多浏览器与真实缩放仍单列验收。无真实模型调用、部署、全局更新或远程发布。

## 执行结果

- A／B已完成：Tooltip按对象跟踪焦点／悬停／提示悬停，主动关闭用弱引用集合记录；离开B可回到A，不因任意按钮聚焦而保留B。固定终态文案与正文共用；通知键包含会话、任务、阶段、停止、在途及提案标识，不包含模型文字，不把旧任务的失败当成当前结果。
- 通知测试通过MutationObserver计数验证：排队、运行、写入在途、停止请求、失败、中断、停止、未知、完成；相同任务重复同步不重复写状态区；不同任务同终态更新；completed伴随未知标记仍按未知通知；旧任务失败不覆盖最新完成。
- 最终隔离Chrome五项通过：原工作区两项、独立任务页面一项、共享Tooltip一项、真实浏览器→BFF→Agent→临时PG一项。共享提示覆盖A焦点／B悬停／离开回A、移入提示保持、Esc后scroll／resize不恢复、再聚焦、待显示取消。实际PG链路仍保证预览／取消不入库、批准后单条候选及关联审计。
- 相关控制台／模板回归59通过，Ruff与格式检查、架构及契约检查通过；服务端wheel160份源码／资源逐字节一致。未改变依赖、API或迁移，没有扩大到真实员工／供应商测试。
- 工作在原Agent分支本地提交。运行证据与构建产物保持忽略，不进入源码；真实读屏播报、Windows、多浏览器、实体设备和实际缩放未验收。本轮测试不是全仓库／全数据库／完整安全重验。
