# 共享组件状态审查与统一方案

日期：2026-10-27。适用控制台22份模板，共享CSS／交互模块统一处理，不按页面复制组件。当前为源码优化，未部署运行实例。

## 审查范围与结论

| 类别 | 审查内容 | 本轮处理 |
|---|---|---|
| 输入与选择 | 默认、悬停、焦点、禁用、只读、错误、占位、原生picker兼容 | 延续单圈焦点；补只读／禁用背景及占位色，保持真实表单语义 |
| 按钮与图标 | 主次危险动作、禁用、提交中、悬停与触屏区域 | 区分禁用not-allowed与aria-busy等待；禁用不触发悬停增强；补次要／危险动作反馈与44px触屏目标 |
| 筛选与分页 | 默认10条、折叠高级筛选、真实页码、取消恢复数量 | 沿用共享筛选和分页组件，复验导航／草稿保护，不另造分页 |
| 表格与长内容 | 窄屏、长标识、容器内横向滚动、详情入口 | 保持内部滚动与详情弹窗，复验全部模板五种宽度 |
| 弹窗与浮层 | 键盘、Esc、焦点返回、原生picker优先、通知层级 | 复用现有dialog／popover和Tooltip回归；不增加动画库 |
| 异常与异步 | 错误摘要、就地错误、禁用还原、等待回执、未知结果 | 保持服务端授权／校验边界；不以视觉禁用代替鉴权，不自动重放写入 |
| 减少动态效果 | 按钮和控件过渡、通知、侧栏 | 扩大CSS reduce-motion覆盖至普通按钮，保留既有专用规则 |

## 实施边界

- 不修改角色、权限、接口、数据库或业务模型；用户提供的无关未跟踪文档保持原样。
- 只读输入仍可聚焦和复制，保持可见焦点；disabled仍由原生控件阻止操作。禁用不等于正在提交，仅处于aria-busy区域时显示等待光标。
- 触屏扩大的是操作区域，不放大SVG图标；全模板布局需重新核验，避免表格或弹窗溢出。
- 不承诺所有系统原生日期／选择弹层外观一致；增强能力不足时保留原生回退。当前控制台没有完整深色主题，不把暗色验收计为通过。
- 现有实例仍运行旧样式；本次提交使旧发布候选过期，后续须基于最终源码重建。

浏览器测试覆盖全模板布局、对比、键盘和表单流程；新增状态测试直接验证只读可聚焦、禁用悬停稳定、等待光标、减少动态效果与触屏真实尺寸。本轮33项隔离浏览器测试通过；最后补齐触屏筛选／分页尺寸和禁用行图标样式后，针对状态、全模板布局和视觉对比的3项回归再次通过（包含在上述覆盖范围，不重复累计）。Ruff、格式、文档链接与diff检查通过。测试曾因颜色过渡中间值失败，已改为等待目标CSS状态后验证，没有以固定sleep或删除断言规避。
