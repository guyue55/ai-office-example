# UI独立审阅整改计划

日期：2026-10-27。目标仓库：ai-office-example，Agent分支。

## 范围与约束

修复独立审阅发现的七项问题。复用现有Web会话、实时权限、预览摘要、版本与幂等；不增加身份旁路、不调整企业角色默认授权、不新增业务字段或模型服务。展示内容只能来自服务端核实的资料或实际预览，不能信任隐藏字段中的显示姓名。所有密码、令牌和运行配置继续排除。

## 实施顺序

1. 账号确认：展示目标、提交字段和变更前后值；关联目标通过原受控搜索重新核实ID，资料无法核实时阻断关联预览。额外读取复用应用层能力，不直访数据库或身份HTTP，不改提交协议。
2. 助手覆盖边界：桌面并排模式保持非模态；全覆盖窄屏隔离背景及循环焦点，关闭／宽度变化恢复。不能影响共享弹窗和Popover。
3. 员工工作台：按实际能力展示Web助手和本人授权；无能力时保留联系管理员说明。
4. 助手未启用：明确草稿可用但不能发送，示例入口不冒充执行；状态变化更新说明，不删草稿或历史。
5. 任务预览：与侧栏复用同一个摘要渲染器；完整服务器预览和原审批参数保留，无JS仍可核对。
6. 页面定位：服务端统一路由归属与位置名称，导航高亮和面包屑同源，无JS仍能定位。
7. 密度：单页隐藏翻页／跳转，保留总数与每页数量；短表单统一最大宽度，避免无用途大空白。

## 验证

逐项覆盖成功／失败及权限边界；账号关联篡改或搜索未匹配、修改资料旧值、无JS预览；窄屏键盘／宽度切换／弹窗焦点；普通员工能力组合；禁用助手草稿提示；任务摘要及完整预览；详情路由定位；一页／多页分页及抽屉流程。运行相关离线、隔离浏览器与全页面布局，静态类型／架构／契约门禁。发生公共JS变更时扩大助手会话／审批回归。

真实实例原配置绑定的局域网IP已不在当前网卡上。先进行只读诊断，不通过伪造IP或删除身份配置绕过；恢复访问与重新登录有独立验收边界。未恢复前不能声称真实浏览器端到端通过。
