# 模型响应预算与测试生命周期加固

范围：修复81021a0审查复现的响应无限制读取，以及模型调用结束后取消导致started遗留；同步检查压缩、错误体、资源关闭、收尾失败和并发恢复。独立PG／合成HTTP与浏览器验收，不改真实实例、不调用付费供应商。

## 方案

1. 托管模型HTTP设置独立传输预算，普通请求默认原始和解压后各4MiB，合成探针固定额外收紧为各64KiB，运维可在64KiB至16MiB内调整；不复用业务output_bytes。流式检查，Content-Length仅作提前拒绝，不能取代实际计数；错误体同样限额。
2. 出口统一处理identity／gzip／标准zlib deflate，使用有界解压；其他压缩、损坏／截断／拼接压缩拒绝，不交SDK无限制解压。关闭所有成功／失败／取消流，保持原Host／SNI、DNS及重定向策略。SDK不另行自动重试。
3. 将测试收尾封装为独立生命周期组件：开始、结果、取消与中断全链路覆盖。结果存在时优先保存完成事实；未知结果记interrupted。独立有界收尾任务不因请求取消直接取消；进程内保留并观察任务，关闭时等待。收尾失败安全留日志并在后续读取／测试前恢复无实际运行任务的started，不依赖重启，也不重发模型。
4. 活跃测试ID及收尾任务在单执行进程内维护，恢复排除真实活跃测试。取消后尚在收尾时继续禁止新的连接测试，避免重复计费及恢复误判。权限撤回不抹掉已发生结果，响应权限仍重新检查。
5. 负向回归覆盖超限／压缩炸弹／错误体／关闭、网络与结果落库阶段取消、重复取消、收尾失败恢复、并发恢复及三协议。已确认的新问题一并修复，不把静态推测当实证。

## 相邻问题的处理

1. 取消请求后释放互斥但回执仍在落库，可能让用户再发计费测试：独立任务持有active ID，收尾完成前拒绝新测试。
2. 已执行测试却找不到开始记录时曾可能假报保存成功：已用独立PG中的不存在ID验证返回失败。
3. 只覆盖重启恢复会让DB暂时故障遗留记录长时间显示进行中：后续配置读取／操作按最多100条恢复，排除活跃ID，跳过仍锁定记录，不重发模型。开始事务和恢复共用guard避免快照竞态。
4. 巨长Content-Length可能使整数字符串转换本身失败：转换前检查字符和长度，正文不读取，保证关闭。异常类别与正文内容分离。

## 限制

单执行进程约束不变；数据库持续不可用时无法强行保证落盘，进程强杀可能丢失尚未提交的结果。恢复只标未知，不宣称供应商未调用／未计费。关闭时只等待本组件已登记收尾，原HTTP服务仍负责请求排空。压缩仅identity／gzip／标准zlib deflate；其他编码拒绝而非不受控降级。HTTP预算不替代Token、业务输出和部署资源预算。

本轮不新增数据库迁移，head仍0015。当前业务实例、真实供应商、全局CLI／技能均未更改，未推送／发布。审查复现和本轮测试使用合成输入及独立临时PG，未读取真实凭证。
