# 模型配置主流程实施计划

依据：MODEL_SETTINGS_UX_RESEARCH.md，基线0a9c556。初始范围为模板源码开发及隔离验收，不替换在用实例。后续用户明确要求复核真实问答，增加既有实例模型修订切换与两轮真实只读会话验收；未部署本轮新源码。

## 实施任务与验收顺序

1. 契约拆分连接与模型草稿；新增人工专用目录发现和临时探针操作，不向Agent/MCP开放。
2. 三协议模型目录复用既有异步客户端、鉴权和受控transport；目录数量／页数／字节／总时限有界，失败保留手填通路。
3. 扩展现有测试记录允许临时配置、请求去重；复用取消收尾与恢复，不生成正式配置修订，不因刷新页面重放收费请求。
4. 新密钥临时加密仅存内存；已有密钥按原修订服务端读取。更换目标地址时明确确认沿用旧密钥，不回填秘密。
5. Web改为URL、密钥、模型与就近操作；可编辑模型选择、刷新、临时测试、局部回执、参数变化失效；高级与修订详情折叠。无JS保持手填和表单操作。
6. 保存并启用复用保存／应用操作；部分成功明确显示，不自动重复测试。原管理API保持兼容。
7. 先写失败测试，再逐层实现；独立Agent、完整非live、隔离PG、浏览器与双镜像运行验收；更新契约、文档并本地提交。

## 范围控制

单个服务端助手默认模型，不增加多供应商平台、计费系统、自动选模型或批量推理。目录可见不代表模型可推理；测试通过不代表业务工具全部可用。瞬时测试回执不自动迁移为已保存修订的验证证据。模型与真实密钥不进入日志或前端持久存储。

## 完成与验证（2026-10-29）

上述七项已实现。完整非live回归706项通过，独立Agent回归60项通过；隔离PostgreSQL、迁移、取消收尾、备份恢复及浏览器组合验收8项通过。最终文案调整后，浏览器验收及相关表单测试再次通过。普通镜像和Agent镜像分别构建并运行冒烟通过，Agent镜像覆盖合成供应商的保存、测试、启用、任务、重启与停用。静态类型、格式、架构、模板、能力覆盖及契约快照检查通过。证据保存在忽略的runtime/model-setup-research目录；合成验收不冒充真实供应商验收。

用户追加真实问答检查后发现，基础测试与实际生效修订不同。通过人工控制台启用已测试修订后，原权限问题真实完成，取得本人权限和可用能力两条回执；同会话追问完成。仅变更模型生效修订，未读取或更改密钥，未部署源码，未操作业务写入。模型自然语言说明仍需以实际工具契约与服务端执行规则为准。
