# 智能助手配置页 UI 审阅与优化

日期：2026-10-28。范围：模型配置页和必要共享布局／提交反馈，不改权限、模型执行、加密或当前实例。

## 发现与方案

- 三张全宽卡纵向堆叠、说明重复、状态像长清单：桌面左侧编辑，右侧状态与已保存修订操作，窄屏单列；不加sticky侧栏，避免助手并排／较矮窗口遮挡操作。
- 字段缺少视觉及语义分组：连接、密钥、数据许可与高级预算用fieldset/legend；共享field、check-option、badge、确认和校验组件。标签14px、章节16px、页标题沿用项目；间距8/12/16/24，圆角及颜色继承现有token，不新增字体和主题。
- 相同宽度长表单效率低：常规字段两列，地址／密钥等跨列，预算三列；按可用容器宽度响应，而不是仅按视口（兼容助手并排）。保留系统中文无衬线字体，无需字体网络请求。
- 鉴权／秘密动作不清楚：仅Anthropic显示额外鉴权；保留／清除时隐藏并禁用新密钥，清除给出明确影响说明；无JS仍有完整字段和服务端验证。
- 尚未保存仍能操作旧修订：编辑状态明显显示，未保存时阻止本页测试／启停，提示先保存或还原；只在内存比较非秘密值及“密钥是否填写”，不保存秘密或localStorage草稿。
- 输入预算原生约束不完整：从真实ModelLimits契约取min/max，避免前端写死另一套边界；错误仍复用共享字段反馈，折叠预算包含非法值时展开以便纠正。
- 提交缺少明确等待状态：共享原生确认流程发出提交已批准事件，页面据此禁用重复提交并显示文字等待；取消确认不得进入busy。成功仍用现有toast，失败沿用受控错误页，不自动重试写入。
- 动效只保留已有150ms级焦点／过渡并遵守reduced-motion，不引入时间线、页面入场位移或GSAP依赖。

## 依据与验收

参考[WAI表单分组](https://www.w3.org/WAI/tutorials/forms/grouping/)与[提交反馈](https://www.w3.org/WAI/tutorials/forms/notifications/)，结合ui-ux-pro-max的标签、颜色非唯一反馈、克制动效和键盘可达性规则。GSAP skill用于评估动效边界，当前简单状态变化采用现有CSS。

实现文件：model_settings.html、model-settings.js、settings.css、model_settings.py、workspace.js、ui_catalog.py及页面组件清单。验证：真实临时PG浏览器保存／取消／启停、脏编辑防误操作、鉴权切换、密钥清空、预算范围错误与展开、等待状态、只读、缺少依赖、桌面／窄屏／助手并排／减少动态／无JS；全页面巡视保护共享组件。
