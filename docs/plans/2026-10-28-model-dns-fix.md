# 模型出口Fake-IP兼容修复

## 范围

实现服务端、精确域名范围的DoH JSON解析适配，保留现有出口、TLS、响应预算及测试费用确认。当前只处理可信解析；显式HTTP代理是独立后续扩展，不在此轮加入。不得通过允许所有保留地址、关闭证书或全局修改Clash来绕过。

## 实现与检查

- 测试先行：新增解析器导入用例在实现前失败；随后完成配置校验、异步有界解析、TTL缓存与资源释放。
- 新增`model_dns.py`与部署配置字段`agent_model_doh_url`／`agent_model_doh_domains`；两者须同时填写，默认关闭。
- model_egress仅对精确域名使用新解析器；所有候选地址继续校验，固定IP连接保留Host/SNI。错误增加dns_fake_ip／dns_address，输出模型和契约快照同步。
- 合成测试覆盖双栈、缓存过期、零TTL、CNAME、问题不匹配、坏地址、查询失败、重定向、超限、截断、取消、混合内外网地址及Fake-IP拦截；本轮定向55项已通过。
- 完整回归、静态检查、隔离PG管理链路、普通／Agent容器、真实无密钥网络验证及本地实例应用结果见交付报告。登录和真实模型测试由用户操作，不读取密钥、不自动调用供应商。
