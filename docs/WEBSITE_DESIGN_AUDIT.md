# 网站设计全页审阅与复核

日期：2026-11-05。范围是模板产品的24类Web页面、共享导航／弹窗／助手，以及本地Keycloak匿名登录页面。基于当前源码和浏览器重新检查；历史通过记录仅作背景。本轮没有访问用户登录会话、填写凭证或执行真实账号／权限写入。

## 方法与资料

先巡视桌面及手机截图和页面任务，再用真实模板的隔离HTTP服务检查五种宽度、键盘和失败状态；发现后回查源码、计算样式或实际焦点，再修复并使用同一规则复验。身份页使用新匿名浏览器从控制台发起新登录，不回放旧链接。

| 一手依据 | 本项目的具体决策 |
|---|---|
| [WCAG Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) | 页面在320px宽度重排；需要列间比较的数据表可以局部滚动，不能让整个页面溢出；单元格仍需处理长内容 |
| [WCAG Focus Not Obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html) | 按Esc只处理当前层；不能收起背景导航后把焦点放到隐藏入口 |
| [WCAG Target Size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) | 可选技术详情summary保证至少24px高；登录输入及主要操作采用44px，不把两者混称同一标准 |
| [Carbon Data Table](https://carbondesignsystem.com/components/data-table/usage/) | 保持可比较的表头和列结构，先用现有表格组件补齐任务／操作历史／关联选项，而非为每页新建一套表格 |
| [PatternFly Login](https://www.patternfly.org/components/login-page/design-guidelines/) | 产品身份、登录任务与表单形成紧凑单列；保留父主题标签、自动填充、显隐和错误机制；本实例是v5，不能直接套v6类名 |
| [GOV.UK Error Summary](https://design-system.service.gov.uk/components/error-summary/) | 错误须可定位且有下一步；复用已有有界错误与只读重试，不把失败变成空白或自动重放写入 |

工具采用axe-core 4.10.3（来自官方npm包）辅助检查WCAG 2A／AA、2.1AA、2.2AA及best-practice规则；只置于忽略的研究目录，不成为产品运行依赖。自动扫描未报告违规不代表完整无障碍合规。

## 经二次复核的问题与修复

1. 追踪号的实际对比度约2.65:1、编码约3.92:1。扫描后回查真实样式，均改为共享muted色；新增计算颜色对比度回归。不能为了视觉淡化让辅助信息不可读。
2. 角色说明及关联选项链接与周围文字缺少非颜色区别。添加有范围的正文链接下划线，不影响导航、按钮或图标入口。
3. 技术详情summary实际高度约23.1px。共享summary最小高度设为24px，继续沿用原生details键盘和无JS语义。
4. 完整助手h1后直接出现欢迎h3。渲染器根据完整页／嵌入上下文选择h2／h3，样式与语义分开。
5. 移动端账号菜单打开后一次Esc同时收起导航，并把焦点返回隐藏入口。修复前新增浏览器回归稳定失败；修复后第一次只关账号菜单、第二次关导航，模态确认中的Esc不穿透。原生picker继续优先。
6. 任务、操作历史及关联选项表格没有沿用管理表格的窄屏模式。三处接入现有组件与局部滚动，权限目录继续用卡片，不机械统一所有表格。长连续权限编码改为可换行，并用合成极长编码检验页面不溢出。
7. 真实登录页390px时品牌断行、用户名起点约454px，控件36px高。父主题与覆盖CSS的计算样式确认了原因；调整品牌字距／字号、页顶和卡片留白及阴影，用户名起点约246px，输入与提交44px高。主题只改可维护CSS，不复制身份流程。
8. 最终截图复核发现授权详情／关联页重复显示全局位置栏与旧面包屑，且目标名称又在页头重复。源码确认仅这两页保留旧结构；合并位置说明，详情页提供明确返回列表操作，关联页保留目标名称及返回配置效果入口。无JS仍输出全局位置栏。

## 验证记录与限制

- 修改前：目录／状态／视觉浏览器基线36项通过，仍未覆盖上述缺陷；因此不能把旧绿灯当完整设计审查。
- 同口径axe初扫：48个页面与宽度组合均有报告；46个组合报告颜色对比度，另有正文链接、标题和目标尺寸报告。同一根因会重复出现，不能按节点数量夸大成独立缺陷数。
- 修改后：24页×1440／390的48个组合在所选自动规则中未报告违规；真实匿名身份页1440／390／320三种宽度也未报告违规。扫描不覆盖隐藏状态、全部业务数据、真人读屏或全部WCAG标准。
- 匿名身份专用浏览器回归1项通过：五种宽度、640px短屏、刷新标题稳定、空白凭据、密码显隐及无JS回退。显式受信身份realm参数支持分离部署，不从实际跳转自动放宽来源。
- 全页截图与扫描JSON保存在忽略的runtime/agent-research；不将运行资料或一次性本机地址提交为模板默认值。

尚未验证真实开户／改密／账号限制、首次改密及本人重新认证的身份主题全状态；真人移动软键盘、密码管理器、读屏器与跨浏览器另需专项验收。中英文品牌标题都生成中文的问题仍存在，需单独修改生成器并走安全配置生成验证，未在运行实例中手改生成文件或绕过足迹保护。没有发布或更新企业部署。
