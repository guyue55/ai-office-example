# 控制台与助手整体体验升级

日期：2026-10-26；目标分支：codex/agent。用户要求全局升级；此前局部视觉验收与悬浮入口修复是起点，不代表本计划完成。

## 定位与范围

为普通业务人员提供清晰、低门槛的管理工作台和工作助手。PC优先，同时支持窄屏及键盘。保留服务端权限、CSRF、版本检查、预览确认、幂等、审计与本人会话边界。不得以视觉改造新增业务字段、扩大权限或把模型输出当成执行结果。

采用现有Jinja＋模块化原生JS，统一样式变量和组件；不为了换肤引入React或复制第二套业务状态。完整工作区、侧栏和任务详情复用原会话／回执。模型未配置时必须有准确的不可用状态。

## 统一设计方案

- 外壳：桌面保留深色紧凑导航，统一线性图标、当前位置；窄屏以菜单按钮收起导航，释放首屏；账号保持独立的底部入口。无JS仍能访问链接。
- 内容：统一页面标题、摘要、主动作和卡片密度；有明确主次，不堆叠说明。复杂说明默认收起，但不可隐藏风险、缺数或不可用原因。
- 列表：共用筛选、页码、每页10条及重置语义。主要行操作直接可见，其余收敛。长字段局部换行／滚动，不撑破全页；空态区分无记录与无搜索结果。
- 编辑：短确认用统一弹窗；复杂开户／授权／查看详情用共享抽屉；填写错误就地说明。提交期间防重、失败保留输入；危险动作与普通动作区分。
- 助手：右下角入口、右侧面板、完整工作区统一；清晰输入区域、历史、任务进度、审批与实际回执。图标均有可访问名称及键盘／悬浮提示。
- 反馈：成功用非阻断提示；可恢复错误给操作入口；未知结果不显示为成功；重要安全限制明确可见。
