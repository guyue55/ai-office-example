# Agent 聊天交互实施计划

本轮基于 `ac3b56e`，面向业务人员 PC 工作台。保留原生页面、服务端权威历史、实时权限、逐次审批与幂等；不替换运行时、不增加自动写入重试。

## 研究与取舍

- [assistant-ui 滚动规则](https://www.assistant-ui.com/docs/primitives/thread)：用户查看历史／展开预览时暂停跟随，并提供回到最新。借鉴行为，不引入 React。
- [中文输入组合事件](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/isComposing)：组合输入期间快捷键不提交。
- [Clipboard 安全上下文](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText)：局域网 HTTP 必须有可选择原文的降级路径。
- [markdown-it 安全说明](https://github.com/markdown-it/markdown-it/blob/master/docs/safety.md)：关闭 HTML；在解析结果上采用允许列表 DOM 渲染，不直接插入模型 HTML，禁图片和嵌入。

## 分批计划与验收

1. 输入与阅读：每会话内存草稿、中文快捷键保护、自动高度、发送原因、按任务键增量更新、历史锚点与回到最新。验证切换／轮询不丢输入、不打断旧消息选择。
2. 内容：本地固定版本 Markdown 解析器与许可证，有限 DOM 标签／链接协议、复制与 HTTP 降级。验证脚本、HTML、图片、危险 URL 均不执行；长表和代码不撑开页面。
3. 操作与反馈：按真实操作区分预览，保留完整参数；展示权威执行状态和可核对入口，不展示推理、不伪造进度、不提供盲目写入重试。
4. 会话与布局：服务端本人会话搜索／重命名（版本、权限、审计，所有传输同步），可调侧栏宽度、少量只填入不执行的示例。验证冲突、越权、分页、键盘和窄屏。
5. 综合核查：独立浏览器、隔离 PG、契约／架构／能力覆盖、回归、类型／格式、源包与秘密扫描；同步指南并本地提交。

## 边界

正文和草稿仅在本页面内存，刷新／导航会丢失，离开前提示；浏览器存储仅会话 ID、展开和宽度偏好。SSE、语音、附件、编辑历史、自动排队、物理删除和跨页面草稿持久化暂不纳入。真实模型费用、部署、全局升级和远程推送不在本轮授权内。

## 执行记录

- 1～4 已实现：会话内存草稿及发送期间新输入保护、IME快捷键、自动高度／禁用原因、按任务增量更新／回到最新、受限Markdown／原文复制降级、操作差异摘要与权威状态、本人标题搜索／版本化改名、可调侧栏和只填入的示例。
- 根治两个HTTP环境问题：安全随机字节生成请求标识，避免依赖仅安全上下文提供的randomUUID；剪贴板不可用时提供共用弹窗手动复制。
- 修复通用工作台表单处理器重复接管已preventDefault的组件提交，防止异步发送／搜索后额外导航。没有加入第二套提交或权限机制。
- 模型说明采用markdown-it 15.0.3，固定官方npm包并验证SHA-512；浏览器包SHA-256及MIT／BSD依赖许可随服务端交付。禁止HTML／图片／嵌入和危险链接协议；32000字符／6000展示节点／16层预算超限回退纯文本。
- 静态与基座回归：559通过、83项live不在该命令运行；独立Agent模块53通过；mypy 109源文件、Ruff125文件格式、架构、53项多端覆盖、契约、品牌／技能检查通过。
- 隔离PG：9通过，包含本人／其他员工、旧版本重命名、字面%_搜索及原执行／审批／恢复。使用专用临时容器，没有操作在用实例。
- 隔离Chrome：3通过。验证同源BFF、审批冲突、权限撤销、侧栏／全页与窄屏；新增IME不提交、切换草稿、旧节点保留、安全表格／代码、无Clipboard及randomUUID环境、手动复制、键盘调宽、改名／搜索及延迟回执不清空新草稿。已实际查看合成数据截图。
- wheel构建成功；服务端159个源码／资源文件、客户端15个源码文件与当前构建输入逐字节一致，包含8份解析器／许可／来源资源。已复核44份暂存文件，Gitleaks脱敏扫描约906KB、未发现泄露；运行产物和秘密未暂存。

## 验收限制与后续

本轮验证使用确定性模型替身和独立测试身份，不新增真实供应商调用，不把它称为真实模型质量验收。浏览器为macOS Chrome；未证明Windows端UI活体表现。草稿刷新不恢复、短时HTTP仍属演示、原单进程运行限制均保留。

执行阶段显示现有权威状态（含等待确认、写入在途及停止请求），没有新增逐工具实时事件或流式通道；无回执时仍引导核对，不能盲目重试写入。会话标题查询限本人，列表仍10项及有界翻页，未引入全文索引或无限历史加载。未部署、未更新全局CLI、未推送／发布。
