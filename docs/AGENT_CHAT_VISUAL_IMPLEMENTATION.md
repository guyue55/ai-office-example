## 关键设计决定

- 新会话、历史、发送保留可见文字；更多、收起、复制等使用统一SVG及中文Tooltip。
- 历史浮层是可搜索的非模态对话区域，动作浮层使用普通按钮组，不伪装未实现键盘协议的ARIA菜单。
- 将正常同步提示移为读屏状态，错误／待处理／暂停和权限变化仍可见；重新连接只读，不重发写入。
- 普通只读回执折叠，关键写入回执与缺数／截断／未知持续可见；无需模型生成成功摘要。
- 不删除原确认机制；不新增语音／附件／反馈／重新生成／推送／SSE。
- 测试使用独立浏览器会话、合成数据和临时数据库。真实模型供应商／真实员工可用性、Windows活体和生产验收分别声明，不混作已完成。

## 执行与证据

- 共享层：扩展既有OfficeUI显式SVG／Tooltip，新增floating-panels.js管理非模态浮层、视口定位、互斥、外点关闭和焦点恢复；既有表格仍调用同一图标工厂，确认／详情沿用原统一弹窗。未引入新依赖或动画框架。
- 助手层：侧栏／全页共用头部、历史、菜单、输入、渲染器和执行控制器；菜单只承载低频操作。普通同步隐藏视觉占位；错误／暂停／归档／权限变化仍显示。保留原传输与版本校验，修正归档失败时不能清空当前会话。
- 展示层：用户浅底气泡、助手正文留白、空态仅两项填入示例。普通读回执折叠；已知覆盖警告、后续页、排除记录与关键写入回执可见。没有把模型文字视为成功凭据。
