# v1.1.0 发版准备与验收

日期：2026-10-27。目标分支为codex/agent，候选版本为1.1.0；本文件不表示main已合并或已正式发布。

## 范围及修正

相对已发布v1.0.0，本版包含可选员工Agent、服务端助手、持久会话及控制台体验升级，采用minor版本1.1.0。原普通客户端和普通服务不要求启用模型。

- 同步五份pyproject、VERSION、Agent模块版本、两份锁文件、OpenAPI及模板版本状态；锁文件只改变本地发行包版本，没有升级第三方依赖。
- 配置生成器因本机存在实例足迹而正确拒绝直接生成。在独立临时目录执行原生成器，确认唯一差异是template-state.json的版本后回填源码；没有移除实例足迹、修改品牌或迁移身份。
- 发布测试原先写死v1.0.0，现从VERSION读取并保留错误Tag、错包、错锁、错OpenAPI及覆盖拒绝测试。软链保护测试核对原VERSION字节不变，不再写死版本。
- 修正Agent运行指南遗漏的0013会话迁移，要求升级执行全部head迁移；发布说明明确agent.run权限变化、单进程约束和回退边界。

## 当前验证证据

- 48项隔离PostgreSQL／浏览器联合验收通过：受控聚合、数据库就绪与权限、Agent读写／审批／撤权／回执／会话、真实浏览器至临时PG操作，以及共享控件、导航、草稿与提交流程。使用测试身份和模型替身，不访问在用业务库或真实模型。
- 独立Agent运行时53项测试、Ruff及类型检查通过；发布及镜像工作流22项针对性回归通过。
- 普通镜像与OFFICE_AGENT=1镜像均完成本地构建；分别通过docker_smoke的全新临时PG正式迁移、初始化、就绪、认证边界、Host和关闭检查。不改在用容器、不删除既有卷。
- Ruff、格式、服务／SDK及契约类型、架构边界、能力覆盖、技能结构、契约快照及模板配置检查通过。服务与Agent导出的锁定运行依赖分别经pip-audit审计，未发现已知漏洞；审计不是无漏洞保证。
- 修正硬编码版本测试后，全量离线测试597项通过、116项活体测试显式排除；已执行的48项隔离活体测试单独记录，不把其余排除项计为通过。候选构建尚需在源码提交后执行。

## 正式发布前的必要步骤

1. 核对本分支最终变更，推送并通过远端多系统／Python版本CI；受保护main经PR合并。
2. 核对最终main SHA，在该SHA重新构建候选，用prepare_release、verify_release、摘要及隔离安装复核。分支候选不可替代合并后来源。
3. 创建附注Tag v1.1.0和Release草稿，审核17份资产、来源及说明，再正式发布；原v1.0.0不覆盖、不移Tag。
4. 镜像工作流默认发布普通服务镜像；可选Agent镜像在本轮只做本地构建／验证，不能宣称已在GHCR交付。远端镜像发布另核实双架构、摘要、匿名拉取与运行。
5. 实例升级与全局客户端升级独立执行。既有数据恢复、迁移耗时、企业模型／数据政策及目标容量需按目标环境验收；本轮不对在用实例作升级或模型调用。

本机证据不替代Linux／Windows远端矩阵、所有浏览器、供应商协议效果或生产容量验收。当前浏览器仍访问旧部署，不因源码提交自动更新。
