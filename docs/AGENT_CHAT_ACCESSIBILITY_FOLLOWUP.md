# 聊天界面联网复核与可访问性补强

日期：2026-10-26；范围：codex/agent。延续视觉实施，不改执行、认证、审批、数据库或模型配置。

## 依据与决定

- [WCAG 2.5.7拖动操作](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements)：键盘替代与无需拖动的单指针操作分别判断。侧栏增加原生宽度选择，复用现有setWidth与偏好存储；不新增常驻工具栏，拖动和键盘继续可用。
- [WAI Tooltip指导](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)：聚焦与悬停均可展示，Esc关闭且不夺焦点。该模式仍有讨论中的说明，不宣称完整标准认证。仅在悬停路径判断hover:none，键盘聚焦在混合输入设备继续生效。
- [WCAG重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：补测320 CSS像素和低高度下操作可达。窄视口是重排相关证据，不冒称真实浏览器200%／400%缩放或读屏验收。
- [WCAG目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)：AA基线24×24 CSS像素，存在例外；44×44是增强等级。不能只看CSS声明认定全部合规。
- [Carbon聊天设计](https://carbondesignsystem.com/community/patterns/chatbot/usage/)支持头部／消息／输入分区的方向；65%消息区是本项目目标，不是行业标准。

## 计划与验收

1. 现有更多浮层加入紧凑360／标准420／宽640选择；受视口允许最大宽度约束，自定义拖动值如实显示，刷新恢复，不跨用户共享正文。
2. 共用Tooltip区分悬停与聚焦；混合设备聚焦可见、Esc关闭，名称仍可供辅助技术获取。
3. 隔离浏览器覆盖320宽、低高度、浮层和发送区、全页不出现无必要横向滚动；发现真实布局问题即修正。保留原草稿／审批／断网／权限撤销回归。
4. 运行相关浏览器／模板回归与静态检查，核对资源打包；同步指南、本地提交，不升级在用实例或发布。

## 执行证据

- 已完成：原生宽度选择与拖动／键盘共用setWidth，菜单在全页工作区不显示此设置。任意拖动值显示为“自定义（N像素）”，预设值按视口最大宽度约束，偏好沿用原会话存储。
- Tooltip保留触屏不依赖悬停的路径；聚焦提示不受hover:none限制。修复指针移出事件关闭仍具键盘焦点提示的问题；自动滚动／视口变化时对可见聚焦目标重新定位。
- 验证中发现原生选择框嵌在label内会把选项算进名称，已改独立for标签，测试按准确中文名称操作，不用选择器绕过标签问题。
- 相关模板／控制台回归59通过，隔离Chrome工作区2项通过；新增预设360／640／420实际宽度、440自定义、混合设备聚焦／Esc、320×640与640×256重排相关模拟。检查输入区／搜索浮层可达且页面不横向溢出，保留原草稿、IME、审批冲突、断网和权限撤销断言。
- 架构、品牌配置、技能、Ruff及契约检查通过。所有测试仅使用隔离应用、合成数据和测试身份，未读取用户会话或模型密钥。
- 最终隔离Chrome三项通过（含原独立任务页面）；服务端wheel重建后160份源码／资源与当前输入逐字节一致，未改变依赖或接口。全部改动保留在Agent分支，本地提交。

真实读屏、实体混合设备和实际浏览器200%／400%缩放仍未验收，不以窄视口或触控模拟替代。65%正文占比属于项目设计目标；本轮不能据此宣称全站WCAG合规。没有部署、推送或发布。
