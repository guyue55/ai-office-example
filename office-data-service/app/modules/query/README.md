# 业务无关的受控查询内核

本模块已实现有限条件、分组、日期分桶、聚合、排序及完整性输出；不保存数据、不获取用户、不管理数据库连接，也不内置客户字段、指标或确认状态。

| 文件 | 职责 |
|---|---|
| schemas.py | 严格输入合同：条件组、字段、聚合与排序；拒绝额外字段及无界表达式 |
| compiler.py | 将适配器提供的授权数据源和字段合同编译为SQLAlchemy查询，检查类型及输出语义 |
| outputs.py | 显式返回数据集、修订、范围、匹配／排除数量、列类型与complete |

当前适配器是../data/query.py：先校验项目结构和本人／全部读取权限，限定每条记录最新确认快照，再调用本内核。编译计划由data适配器通过AsyncSession执行，数据库完成过滤与聚合；不把全表搬到Python计算。

当前合同上限：5个条件组、共40个条件、每个集合最多50值、5个分组维度、8个聚合指标、5个排序键，结果组默认100、最多1000。支持count／sum／avg／min／max及日／月／季／年分桶。实际字段和操作组合还须通过类型检查；精确结构修订、NULL语义、预算和日期口径不能省略。超限失败，不用截断结果冒充完整统计。

不开放原始SQL、任意表达式、JOIN输入、跨项目语义自动合并、批量查询执行、指标口径或统计缓存。未来数据适配器须先完成自己的权限和状态限制，再复用内核，不能跳过授权直接调用编译器暴露数据。
