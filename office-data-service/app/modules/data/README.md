# 项目、记录与确认数据适配

当前项目元数据、动态字段修订、候选记录、确认快照、更正及历史的唯一权威模块；不在catalog重建同类模型。

- schemas.py／outputs.py：纯输入、字段规则与输出合同；无数据库依赖。
- service.py：项目／字段发布、候选记录CRUD、幂等与有界确认导出。
- lifecycle.py：确认冻结、新候选更正、有效确认与不可变历史。
- query.py：已确认数据查询适配器，限制项目、精确修订、当前权限及数据状态，调用[query内核](../query/README.md)，并通过异步数据库会话执行。
- change_contracts.py：封闭数据管理预览／执行合同；编排和公开操作注册在application。

数据录入不等于业务确认；更正候选等待确认时，正式查询仍使用旧确认版本。现有受控多维聚合已实现，但不提供业务指标口径、跨项目语义映射、批量导入、共享统计缓存或完整部门／项目成员级权限。来源采集与后续专项业务留给其权威模块，不能据此把基础记录称作已交付CRM。
