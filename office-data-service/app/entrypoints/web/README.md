# 服务端管理工作台

使用服务端Jinja模板与异步应用入口，提供浏览器登录、本人权限说明、人员／角色／权限集管理、授权详情、审计与智能助手。Agent分支的Web通过同源BFF调用受控服务端Agent；模型配置及调用留在服务端，浏览器不持模型密钥、不直接调用模型。员工端Agent是独立入口，不由Web默认调度。

- `console.py`处理页面、表单与浏览器授权，调用统一Application；不直接查询/写入数据库。
- `session.py`保存进程内有界会话与待登录状态，Cookie只保存签名引用或短期登录绑定。
- `responses.py`集中处理模板与错误页。
- `templates/`包含布局、共享搜索/分页/权限表、独立样式及各页面。

菜单按当前权限显示，写操作仍由后端校验各操作对应权限、CSRF及所需并发版本；权限管理还检查最后管理员约束。人员姓名、账号安全、全企业授权和审计分别使用独立动作权限，不能一律归为access.manage。隐藏按钮不能代替授权。搜索与跨页编辑保留已选项，并允许明确取消筛选外关联。

当前只适用于单进程会话；多worker／多副本需先增加共享会话适配。登录、身份与权限边界见[总体架构](../../../../docs/ARCHITECTURE.md)，Agent运行约束见[运行指南](../../../../docs/AGENT_OPERATIONS.md)。

## 共用交互组件

保留完整页面与原生表单，JavaScript 渐进增强为同页抽屉和短表单弹窗，不另建授权接口。

- `templates/_workspace.html` 是唯一对话框外壳；`base.html` 统一加载。
- `form-state.js` 负责快照、外置选项与授权变更摘要；`workspace.js` 负责加载、预览返回、保存反馈与焦点，不计算真实权限。
- 抽屉响应只提取服务端main内容，不执行响应脚本；相对链接以内容URL解析。完整列表刷新保留原页面外壳与助手入口节点及监听器。写入复用原POST、CSRF与版本契约；结果未知时不自动重试。
- 异步写入前检查其他表单草稿；允许放弃只针对当时的草稿版本，请求期间的新编辑会阻止自动刷新并显示提示。提交按钮按原禁用状态恢复。
- 真正的站内离页通过OfficeUI.confirmNavigation核对助手草稿，避免内嵌浏览器隐藏原生离页提示。抽屉fetch和异步保存不触发，原生刷新／关页仍保留beforeunload；草稿不持久化。焦点与原生select增强边界见[控件方案](../../../../docs/UI_NAVIGATION_CONTROLS_PLAN.md)。
- 抽屉只读加载用请求控制器归属避免旧响应覆盖，aria-busy与中性指示器表达加载；失败显式重试、关闭取消，不自动重放写入。确认弹窗说明与长内容视口约束统一维护于共享模板／样式。
- 助手主动刷新统一调用OfficeUI.reloadPage；业务写入或助手HTTP操作等待回执时阻止站内离页，已受理的后台任务不阻止导航。结束当前授权须先确认助手草稿再发送请求，成功退出后不重复触发原生草稿警告。
- `styles.css` 集中样式、组件 token 与 reduced-motion；禁用与aria-busy提交等待分开，保留只读复制与键盘焦点。组件状态审查见[共享组件审查](../../../../docs/UI_COMPONENT_STATE_AUDIT.md)。不从 CDN 加载脚本或字体。

设计与来源见[UI升级计划](../../../../docs/UI_UPGRADE_PLAN.md)。新增交互须复用上述入口；修改后检查完整页面、抽屉、无JS备用与真实浏览器。新模板和脚本文件须进入wheel资源验证。

账号页面在accounts.py，复用console会话、CSRF、render和统一Application。新建用紧凑弹窗、详情用抽屉，预览／进度与敏感步骤保留完整页面；密码响应不经过通用workspace抓取或AI工具。安全回调区分purpose，校验原身份、nonce与近期认证。实现与验收见[验收记录](../../../../docs/ACCEPTANCE.md)。

当前列表默认每页10条，筛选、数字页码、详情与行操作复用统一组件；账号与客户端授权页面按本人／管理范围展示。会话受控续期不延长绝对TTL，近期再认证与退出流程见[总体架构](../../../../docs/ARCHITECTURE.md)。页面显隐与前端确认不能替代服务端实时授权。助手离页警告不停止轮询，实际pagehide才清理；取消离开应继续核对任务状态。
