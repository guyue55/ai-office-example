# 服务端测试位置

当前真实验证统一位于仓库根 tests，覆盖SDK、HTTP、MCP、Web、PG权限与事务、迁移、安装包；通用契约库还在packages/api-contracts/tests维护独立测试。这里不复制第二套测试。

根 scripts/verify_foundation.py 是门禁入口；活体测试必须显式 --live，只允许独立本机开发环境。结构规则与契约漂移也已纳入门禁。目录存在不表示另有未登记的测试结果。

CI将非活体测试与需要独立PG的容器测试分开；Windows只运行适合员工客户端的测试集合、日报隔离回归、技能检查及轮包安装，不弱化Linux服务端秘密权限检查。测试数量和结论须关联提交，旧的全量活体验收不能替代最新版本结果。当前分层证据见[根README](../../README.md#验证与实际生效)。
