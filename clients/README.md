# 客户端接入

[python/](python/README.md)是可独立安装的HTTP SDK／CLI，支持Python 3.13／3.14。负责浏览器PKCE、系统安全凭证库、同服务并发凭证协调、字段修订缓存与受控请求；无数据库驱动、不在客户端保存业务授权副本、不自动重放写入。

## 当前入口

- `office`／`office -h`：中文分组帮助；`office <命令> -h`：具体参数。
- `doctor`：离线环境检查，不读取凭证、不联网；`auth-status`读取本机授权记录但不联网续期。
- `login`／`whoami`／`logout`：同机浏览器授权、在线身份与退出。MCP宿主单独管理凭证，不复制CLI令牌。
- 项目／字段／记录、候选提交、确认更正、有界确认导出及受控聚合；人员／角色／权限集、账号生命周期和本人／全企业授权管理。
- 管理与数据变更使用封闭的预览／执行入口、摘要、版本和幂等约束；AI须落实实际人工确认，摘要不代表真人已批准。

账号可经受控服务开通、关联、启停、更新及重置；密码由身份服务管理，敏感凭证只经再次认证后的浏览器流程展示，不进入公共CLI／MCP响应。旧身份绑定入口是高级路径，不是唯一开户方式。

安装、生效与帮助见[Python客户端说明](python/README.md)；跨平台环境见[平台说明](../office-skills/references/platforms.md)，授权与恢复见[认证](../office-skills/references/authentication.md)。具体宿主安装发现、OAuth与企微能力需分别验收；没有自动更新器，也未提供异步SDK客户端类，服务端异步与契约库异步适配不等于SDK本身已异步化。
